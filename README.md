# Circle Auto Settings Script

Automates circle creation in The Circle App.

## Features
- Sets Circle Type automatically
- Sets Level to political leader
- Sets State
- Turns off Active toggle

## Install
1. Install Tampermonkey
2. Open this link:
https://raw.githubusercontent.com/YOUR_USERNAME/circle-auto-settings/main/script.user.js
3. Click Install
